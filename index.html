4-Phase Account Switch Protocol

Engineered For Flawless Profile Switching

Executing verified kernel-level handoffs to protect Vanguard integrity and guarantee immediate game readiness.

PHASE 01

Process Kill & Unlock

Terminates active LeagueClient, RiotClientUx, and companion processes by PID and path, granting a 300ms kernel grace period for file handle release.

PHASE 02

Vanguard-Safe Transfer

Vanguard service directories remain untouched. Targeted account session tokens and YAML configuration are atomically deployed to LocalAppData.

PHASE 03

Win32 Hz & Power Plan

Invokes Windows native ChangeDisplaySettingsEx for 144Hz/240Hz and sets Ultimate Performance scheme in under 20ms.

PHASE 04

Direct Game Launch

Launches Riot Client Services with direct League live patchline parameters. The switcher automatically minimizes to the Windows System Tray.
